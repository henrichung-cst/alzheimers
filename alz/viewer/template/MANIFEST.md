# Template chunk disposition

Reference for the live viewer template after the pathway-tab strip
(Phase 3, 2026-05-06). All remaining chunks are live; the pathway / overview
/ sender-matrix / additivity / graph / temporal-v1 / kinase-backbones tabs
were deleted along with their TAB_GUIDE entries, INITIAL_STATE keys, and
view-export branches.

## Adding a new tab

1. Drop `js/tabs/<x>.js` exporting `wire<X>()` and `render<X>()`.
2. Add a `{{ raw('js/tabs/<x>.js') }}` line to `index.html.j2`.
3. Add `<div id="tab-<x>" class="tab-panel" hidden>…</div>` to `body.html`.
4. Add an entry to `TAB_MANIFEST` in `js/02_ui_chrome.js`:
   `{ group, label, filters, requires, wire, render, rerenderOn, [onChange] }`.

The tab button is generated by `_buildTabBar()` from `TAB_MANIFEST`. The boot
subscriber dispatches re-renders via `rerenderOn` / `onChange`. Do not add
per-tab branches to `boot.js`.
