# Kedro Reintroduction for Argo Orchestration

Source: `project_kedro_argo_reintroduction.md` (decided 2026-05-26).

> The memory referenced an SSOT plan at `docs/plans/kedro_argo_reintroduction_2026-05-26.md` (with the agreed Phase-0 inventory), which is **not present on disk**. This doc is the surviving record; recreate the plan file if you resume.

## Decision

As of **2026-05-26**, Kedro is being **reintroduced**, reversing the 2026-05-21 strip (commit `0c2a997`). Driver: the cloud compute platform (`cellsignal/bioplat`) orchestrates Kedro pipelines through **Argo Workflows**. This is the genuine **external-compatibility exception** to the anti-shim rule — not a hedge or a "might switch back."

## Argo mechanism (corrected 2026-05-27 after inspecting `~/Projects/work/bioplat`)

It is **NOT a plugin**. `kedro-argo` is abandoned (PyPI 0.0.2, kedro-0.16 era) and `kedro-docker` is unnecessary. The bioplat convention is a **thin, hand-authored `WorkflowTemplate`** in `manifests/base/` whose steps run:

```
kedro run --pipeline=<name> --env={{workflow.namespace}}     # or --to-nodes=<node> for finer steps
```

- **Kedro owns the inner DAG; Argo owns outer step orchestration.** Argo step granularity is independent of Kedro node granularity (a template step can bundle multiple nodes).
- `--env` maps to `KEDRO_ENV` (the cohort-selection overlay → `--env={{workflow.namespace}}`).
- Live examples in the bioplat monorepo: `services/conjugation-portfolio` (`kedro run --to-nodes=$NODE_NAME`) and `services/protein-structure` (`steps:` per pipeline).
- The `WorkflowTemplate` + `Dockerfile` + manifests are scaffolded by the **`bioplat-deployer`** agent, not generated by a plugin.

**Consequence:** Phase-1 dependencies collapse to **`kedro` + `kedro-datasets` (S3)** only. The old `click<8.2` / `rich<15` caps (which came from `kedro-docker`) are no longer forced.

## Constraints (decided)

- **In place** — no new repo/folder. Forking would duplicate code guarded by byte-exact parity gates.
- **Full `DataCatalog`.**
- Cohort selection stays the `KEDRO_ENV` overlay (→ Argo `--env={{workflow.namespace}}`).
