## Decisions (locked, P3 grill 2026-06-25, one question at a time)

**Pool — all 60, not 50.** The kinase pool is already materialized: `outputs/reports/kinase_attribution_human/ctrl_audit/concordance_AD8_excl01_03/overlap_AD8_sus_clean.csv` (60 unique kinases, **all ST**, 0 pY). The TODO's "50" is an approximation; C5 uses **all 60** — trimming to 50 by some NES sort would silently drop genuinely-agreeing kinases (against keep-everything). The pool is the strict three-way agreement: AD-group & suspect-group FDR<0.25 same-direction AND all 8 AD donors concord AND both suspects (CTRL-08/10) concord AND all 4 clean controls (CTRL-01–04) oppose. C5 reads only the kinase-name column; pool selection stays **frozen** (a regrouping would re-run the concordance step — out of C5 scope, and is itself one of the things C5's results may justify).

**Q1/Q2 — Human profile = `b-donorset` (suspect-as-AD, swappable).** The human substrate profile is built by the **D1 per-donor builder over an explicit AD-donor-set parameter**, default `AD8 ∪ {CTRL-08, CTRL-10}` — suspects are AD *by construction* (members of the donor set), per the one-off policy. Swapping to the official grouping = pass `AD8` (drop the two suspects), one argument; no code change, no artifact regeneration. Direction = per-donor sign-votes over the set. **NOT** the frozen `overlap_AD8_sus_clean_substrates.csv` group-contrast LFCs — that file bakes the grouping in (separate `lfc_AD`/`lfc_suspect` columns needing an ad-hoc combine rule) and can't be re-pointed. Cost of b-donorset: the compared substrate set is per-donor recurrence, not byte-identical to the group-FDR leading-edge that *selected* the pool — accepted (selection and comparison are legitimately different lenses). The frozen `..._substrates.csv` is therefore never read by C5 → its filename discrepancy (`substrates_leading_edge.csv` vs on-disk name) is moot.

**Q3 — Mouse target = full sweep, cortex-12mo headline.** 5xFAD side = **2 tissues × 4 ages = 8 matched-mode D1 invocations** (cortex/hippocampus × `TG_vs_WT_{3,6,9,12}mo`), **ST track only** (pool is 100% ST; zero pY overlap). All 60 kinases are present in both ST tissues. Deliverable = a 60-kinase × 8-context matrix of `jaccard`/`direction_agree_frac`/`direction_corr`; **cortex-12mo is the headline** (closest to established human cortical AD), the other 7 contexts are the per-kinase breakdown lens — a kinase agreeing at 12mo but diverging at 3mo, or in cortex but not hippocampus, is exactly the "agreement breaks down" signal. Mouse profile per contrast = the group-level `{tissue}_st_mea_stoichiometry.csv` leading-edge (single contrast, no recurrence gate).

**Q4 — Recurrence threshold M = 1; carry + surface support.** A motif enters the human profile if its leading-edge appears in **≥ 1 of 10** donors (keep-everything, no pre-pruning). `support` (donor count) is carried on every motif and surfaced. **Honesty guard (mandatory):** at M=1 a low `jaccard` can reflect donor **sparsity**, not real mouse↔human divergence — so C5 output must (a) surface the human-side support distribution, (b) stratify/annotate kinase summaries by support, and (c) state this caveat in the MANIFEST. The metric stays faithful by being read correctly, not by dropping singletons. M is a documented parameter (sensitivity sweep is one argument away).

**"Flag where agreement breaks down" = a ranking, not a filter.** Emit continuous `direction_agree_frac` / `jaccard` / `direction_corr`; sort ascending; the reviewer sets the bar. No baked-in T/J threshold (explainable metric, no hidden cutoff).

**Naming — no case-flip for kinases.** Kinase names are UPPERCASE on both cohort sides (kinase-library convention) → the 60-kinase list matches 5xFAD names directly. Substrate *gene*-symbol case (UPPERCASE human ↔ Title-case mouse) is handled by D1's optional gene-case disambiguator via `data/derived/caches/human_to_mouse_homologene.csv`; **19/60 kinases are absent from that 389-row cache** → their substrate genes land in D1's explicit unmatched-gene report (motif matching itself is case-insensitive and unaffected).

## Stages

**Stage 1 — Pool loader.** Read `overlap_AD8_sus_clean.csv` → list of 60 ST kinase names (trivial 6 KB read). No selection logic beyond reading the frozen list.

**Stage 2 — Human donor-set profile.** Call D1's per-donor builder with `ad_donor_set = AD8 ∪ {CTRL-08, CTRL-10}` (parameter, default), `M = 1`, filtered to the 60 pool kinases. Reads `mea_perdonor.csv` (10.7 MB) + human `stoichiometry_matrix.csv` (3.4 MB), DuckDB-streamed, pool-filtered at scan — never the 116 MB `mea_substrate_sets.csv`. Emits `{motif: (direction, support, gene, site_position, track=ST)}` per kinase.

**Stage 3 — Sweep the 8 mouse contexts.** For each (tissue ∈ {cortex, hippocampus}, age ∈ {3,6,9,12}mo): build the mouse profile from `{tissue}_st_mea_stoichiometry.csv` leading-edge at `TG_vs_WT_{age}mo` (bridge motif→site/gene via `{tissue}_st_stoichiometry_matrix.csv`), then run D1 `compare(human_profile, mouse_profile)` in **`matched` mode** over the 60 kinases. 8 invocations.

**Stage 4 — C5 summary.** Assemble the 60-kinase × 8-context matrix from D1's `kinase_summary.csv` outputs: per (kinase, tissue, age) → `jaccard, n_shared, n_a_only, n_b_only, direction_agree_frac, direction_corr, human_support_min/median` . Rank ascending by `direction_agree_frac` (then `jaccard`) for the breakdown view. Headline table = cortex-12mo. Per-kinase Venn / direction-scatter (D1 figures) for the headline context. MANIFEST records: pool source + count (60), donor set, M=1 + support caveat, the 8 contexts, headline = cortex-12mo.

**Stage 5 — Runner + task.** Thin module `alz/cross_reference/c5_mukesh_5xfad.py` orchestrating Stages 1–4 (imports `substrate_motif_compare`, never reimplements the engine). Pixi task `c5-mukesh-5xfad`. Output → `outputs/reports/substrate_compare/c5_mukesh_5xfad_<run>/`.

## Verification
- Pool = exactly 60 ST kinases read from `overlap_AD8_sus_clean.csv`; all 60 resolve in both 5xFAD ST tissues (0 missing).
- Swap knob: passing `ad_donor_set=AD8` (drop suspects) changes the human profile and re-runs without code edits — confirms b-donorset is parameterized, not baked.
- A known concordant kinase lands high `direction_agree_frac`; a known divergent one (the "interesting" flag) lands low; both trace to real site-LFC signs in each cohort.
- **Honesty:** human-side `support` distribution is surfaced; at least one low-support (1–2 donor) human motif is PRESENT with `support` shown, not dropped; the jaccard-vs-sparsity caveat is in the MANIFEST.
- **Memory:** runs under cap; peak RSS reported; no whole-file pandas read of any `mea_substrate_sets.csv` (116/104 MB) or substrate matrix — DuckDB-streamed, pool-filtered at scan.
