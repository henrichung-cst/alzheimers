## Input — gated pathway rows
`outputs/reports/incytr_pair_mode/wide/` — 9 parquets, one per contrast, gated in-place by `filter_significant_paths.py` (canonical floor: `SigProb > 0.1` either condition AND `|PDS| >= 0.2`, uncapped). ~4.48M rows total (8–49 MB/file). **Must be read DuckDB-streamed.**

Schema (confirmed via DuckDB DESCRIBE): `Sender.group, Receiver.group, Ligand, Receptor, EM, Target` (the 6-tuple identity), `PDS`, two contrast-specific `SigProb_<cond>` cols (e.g. `SigProb_ma_2mo_AppP`, `SigProb_ma_2mo_WTyp`), plus per-channel sclog2FC/pr/ps/py/Ack/KGG columns. **No `contrast` column** — it is filename-encoded.

## Contrast → (condition, timepoint)
Filename `ma_<age>mo_<Geno>_ma_<age>mo_WTyp_incytr_output.parquet` → regex `ma_(\d+)mo_([A-Za-z]+)_ma_\1mo_WTyp` → normalize geno (`AppP→App, Ttau→Tau, ApTt→ApTt`) → contrast `f"{geno}_{age}mo"`. **condition** = `contrast.split("_")[0]` ∈ `DISEASE_GROUPS=[App,Tau,ApTt]` (== C1's genotype axis); **timepoint** = `2mo|4mo|6mo`. Pattern already used in `song.py:_pair_mode_contrast_from_filename` (709) + `_write_incytr_pair_pathways` (904, injects `'{contrast}' AS contrast`). B5 injects `contrast` per file when unioning.

## Annotation substrates — RESOLVED (one canonical method, no aggexp)
**`mean_gene_specificity`** ← `song_expression_specificity.csv` (`config.SONG_EXPRESSION_FILE`, long-form `cell_type, gene_symbol, specificity_score, tau, top_cluster, top_share`), the **same file the kinase tab reads** (`attribute.py:344 → prepare_song_specificity`). Computed by `snrna_integration.py:step_specificity()` as the CPM-pseudobulk share over `config.CLUSTER_SPINE` — the **Levy-t5 spine**, i.e. the SAME vocabulary as `Sender.group`/`Receiver.group` → direct `(gene, cell_type)` join, no remap. **aggexp.csv is rejected** — it is SCT-normalized and a *second* method for the same concept (the user's "why two ways" call). The 31-vs-46 denominator question dissolves: we read the canonical file, not recompute a share.

**`min_cell_count`** ← `pseudobulk_cell_counts.csv` (`config.SONG_CELL_COUNTS_FILE`, `sample, cell_type, n_cells`) — spine `cell_type` labels (clean join, no suffix-strip), same provenance as specificity, numerically == the byte-verified `yuyu_clustersize.csv`. males_only scope (`ma_*` samples).
