INCYTR INTEGRATION FILES RELOCATED — 2026-05-08

The legacy Incytr integration source (R wrappers, Python adapters,
sidecars, tests, and orchestrator shell scripts) has been moved out

    it ("kept, possibly trimmed").

    left in place — orphaned, but harmless. Delete when convenient.
