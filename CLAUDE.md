## Pair-mode Incytr — sce4 parity constants (do not revert)

Six call-site overrides in `alz/incytr_pair/incytr_commandline.R` and `alz/incytr_pair/build_input_gene_list.R` are required to reproduce sce4's `Top300_table` reference (573/600 Microglia → Cholinergic.Neurons with all 27 misses App-ligand, 599/600 Ndnf×Ndnf, max `|Δ sclog2FC|` = 0 on R/T). Reverting any one of them causes the regression check `pixi run verify-incytr-sce4` to fail. Investigation history: `bench/bench.md`. Propagation record: `docs/plans/sce4_fix_propagation_2026-05-23.md`.

**Receiver gene.use (A33, corrected by A36):** `dg_by_cluster = DEG ∪ prG` per cluster, where `prG = genes with |pr_log2FC| > 1` and **`pr_log2FC` is computed the way the Incytr scorer computes it** — `limma::normalizeBetweenArrays()` (quantile normalization across all genes) on the floored `[cond1, cond2]` pr columns, *then* `log2`. It is **NOT** the raw column ratio. Computing prG on the raw ratio (the pre-A36 bug) drops exactly the genes the scorer flags as pr-significant: e.g. Acvr1/Cholinergic raw ratio = 0.846 (excluded) but quantile-normalized = 2.04 ≈ sce4's reference 1.997 (included). This was the cause of the long-standing "Acvr1 4× gap" — not clustering, not bulk, not a missing file. See `incytr_commandline.R:161-172`.

**The decomposition that feeds the Incytr inputs uses the PROVENANCE deconvolution, not the levy_t5 forward-projection share.** `alz/incytr_pair/export_decomposition_for_pair.py` runs `P_c = (N_total/N_c) × bulk × (specific_c / Σ_46 specific)` with min/10000 imputation: transcript share from the frozen `aggexp.csv` (the one unrecoverable upstream step — it is `AggregateExpression(slot="data")`, an SCT/model normalization baked into a Seurat object not on this box; the h5ad `.X` cannot reproduce it, raw counts give 50.0 and CPM gives 305.9 vs aggexp's 350.3), cell-count size factors regenerated byte-exactly from the Song h5ad, bulk from the frozen per-group medians (`pr/imac/py_median.csv`). This **replaces** the prior levy_t5 `log2(CPM+1)×bulk` share for the Incytr inputs (the levy_t5 `f_c×bulk` forward projection still serves the MEA decomposition — different consumer). With this, the **derived** (production-regenerated 31-spine) inputs reproduce provenance: Acvr1/Cholinergic ma_2mo = 50.70/28.21, Microglia→Cholinergic **573/600**, Ndnf×Ndnf **599/600**, max `|Δ sclog2FC|` = 0 on R/T. The frozen 46-cluster inputs (`bench/validate_frozen_parity.sh`) give the same. Full audit: `docs/plans/sce4_decomposition_reconciliation_2026-05-24.md`.

**App-transgene residual (only residual, documented).** All Microglia→Cholinergic misses (27) and the Ndnf EM outliers (7) are the App transgene. sce4's Oct-2025 run pr ranked App into gene.use, but every pr reproducible on this box gives App fc2 rank ~4523/6687 (pr_log2FC −0.345) — no fold rule (prG |log2|>1 or top_n(500)) recovers it, and App's scRNA sclog2FC also diverges (Ndnf EM 0.19 vs sce4 7.65). This is an isolated input-provenance gap on the transgene, NOT a method error. `verify_sce4_parity.py` PASSES a sub-595 recall iff every miss is an App-ligand path, and tolerates Ligand/EM `|Δ sclog2FC|` outliers only when the position gene is App (`--transgene`). Do NOT fabricate the App paths to force 600.

1. **DG no-cap** — `build_input_gene_list.R:136` filters on `avg_log2FC > 1.5 & p_val < 1e-4` unioned with HEG; **no `top_n(500)` cap**.
2. **`pmax(pr_*, 1)` floor** — `incytr_commandline.R` (floor_pr function) floors deconvoluted protein values < 1 to 1 (pr_yuyu carries ~1e-5 deconvolution residuals that otherwise get amplified by Cal_foldchange's correction-on-zero branch).
3. **`Expr_bygroup(mean_method = NULL)`** — `incytr_commandline.R:382` uses trimean (`NULL` ⇒ `0.25·Q1 + 0.5·Q2 + 0.25·Q3`), not arithmetic mean; the latter inflates SigProb for sparse-expression genes.
4. **`Cal_SigProb(correction = 0.01)`** — `incytr_commandline.R:389` overrides the package default.
5. **`cutoff_SigProb = 0, cutoff_PDS = 0`** — `incytr_commandline.R:213-214,388,414`; sce4 emits all paths and filters downstream. The downstream half is `alz/incytr_pair/filter_significant_paths.py`: `(SigProb_<disease> > 0.1 OR SigProb_<WTyp> > 0.1) AND abs(PDS) >= 0.2` (collaborator's `cutoff_SigProb=0.1`/`cutoff_PDS=0.2`), wired into `run_pair_mode.sh` + `bench/run_nboot0_w3.sh` after the contrast loop and applied retroactively to `wide_nboot0`. Pure row subset, parity-preserving (drops 0 recalled paths; sce4 Top300 survivors sit on/above the cutoffs). Replaces the viewer's former `|PDS|>=0.30` storage cut. Do NOT raise the driver cutoffs to 0.1/0.2 — the filter is downstream of the driver.
6. **`Cal_scFC(correction = 0.01)`** — `incytr_commandline.R:435` overrides `analysis.R:248`'s default (`1e-5`). The 9.95 log2 saturation gap between our pre-fix output and sce4 was exactly `log2(0.01 / 1e-5)`. Downstream code paths that recompute sclog2FC from the transcript substrate must use ε = 0.01 (see `alz/integration/verify_pathway_round_trip.py:94` and `alz/integration/build_normalized_substrate.py`).

Known residual: the App transgene (27 App-ligand misses on Microglia→Cholinergic, 7 App-EM `sclog2FC` outliers on Ndnf×Ndnf) — an isolated input-provenance gap, documented and gate-exempted above. See `bench/bench.md §App transgene residual`.

## Mass identity (decomposition verification)

`Σ_c [P_c × (N_c / N_total)] ≈ bulk`, **not** `Σ_c P_c = bulk`. The `f_c` weights are per-cell rates × N_total/N_c; literal summation overshoots.

## Pipeline-specific gotchas

- **`analysis_mode` flow** — Kedro parameter in `conf/base/parameters.yml`, default `males_only`. `KEDRO_ENV=full_cohort` overlays the sensitivity config. Affects `enrich.py`, `attribute.py`, `mechanism.py` — **not** `normalize.py` (always uses all 72 samples). Legacy `ANALYSIS_MODE` env var was retired and is silently ignored.
- **Outlier detection requires stoichiometry** — `alz/ingest/song.py --outliers` reads `stoichiometry_matrix.csv`, so `normalize.py` must run first. Falls back to total proteome if unavailable.
- **WMB prerequisite** — `run_live_pipeline.sh` gates on `wmb_kinase_expression.csv` / `wmb_proteome_expression.csv`; run `run_wmb_expression.sh` first.
- **WMB region scope** — `WMB_REGION_SCOPE` defaults to `whole_brain` (correct for the specificity score's brain-wide denominator). `cortex_hpf` is a sensitivity toggle only. Active scope is stamped to `wmb_kinase_expression.scope.json`; a scope mismatch forces recompute.
- **Atlas cache compressed** — raw h5ads under `data/external/allen_abc/` are zstd-compressed (~115 GB → ~26 GB). Decompress with `bash alz/runners/supporting/decompress_atlas_cache.sh` before re-running `wmb_expression.py`. Provenance in `data/external/allen_abc/MANIFEST.json`.
- **WMB expression memory** — `wmb_expression.py --proteome` processes 6,308 genes × 13 regions; use `skip_regional=True`, `chunk_size=2000` to stay under ~30 GB RAM.
- **Stage 6 pY track gating** — `build_celltype_decomposition.py --track py` (or `both`) requires `raw_phospho_normalized_pY.csv` from Stage 1. Smoke runner tolerates missing pY; re-run `pixi run normalize` if you need it.
- **Unified-viewer hard refresh** — `build_unified_viewer.py` inlines PAYLOAD as `<script type="application/json" id="payload-data">` into `index.html`. After `pixi run viewer`, hard-refresh (Ctrl+Shift+R / Cmd+Shift+R) or the cached HTML serves stale data. Quick check: `PAYLOAD.meta.generated_at` in DevTools.
- **API caching** — delete `data/derived/caches/` to force re-fetch from MyGene / Allen Brain Atlas.
